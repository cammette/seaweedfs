# blob 迁移测试

从集群 A 的卷文件读取 needle，经集群 B 的 master 和 volume 写入。目标 fid 与源 fid 相同，不调用 Filer。进度写在本目录的 `state/`。

| 集群 | 角色 | master | volume | 卷目录 |
|------|------|--------|--------|--------|
| A | 源 | http://127.0.0.1:9333 | http://127.0.0.1:8080 | `a/data/volume` |
| B | 目标 | http://127.0.0.1:9334 | http://127.0.0.1:8081 | `b/data/volume` |

以下命令在 `test-env` 目录执行。不要和 `blob_sync` 同时往集群 B 的同一批卷写。

## 1. 准备

```bash
cd /ex-bingo/github/seaweedfs/test-env
(cd .. && go build -o test-env/weed ./weed)
./start.sh a
./start.sh b
./status.sh
./prepare_demo_data.sh
```

确认源卷 fid：

```bash
for f in a/data/volume/src_demo_*.idx; do
  vid=$(basename "$f" .idx | sed 's/src_demo_//')
  sz=$(stat -c%s "$f")
  [[ "$sz" -gt 0 ]] || continue
  echo "=== volume $vid ==="
  ./weed export -dir=./a/data/volume -collection=src_demo -volumeId="$vid"
done
```

重跑整次测试时先停集群 B，再清目标和进度：

```bash
./stop.sh b
rm -rf b/data blob_migrate/state
./start.sh b
```

## 2. 迁移

```bash
./weed migrate.volume \
  -mode=blob \
  -masters=127.0.0.1:9334 \
  -dir=./a/data/volume \
  -collection=src_demo \
  -collectionDst=src_demo \
  -replication=000 \
  -stateDir=./blob_migrate/state \
  -verifyMode=crc \
  -workers=2 \
  -decompress=true
```

只迁某一个卷时加上 `-volumeIds=9`。期望该卷 `failed=0`，进程退出码为 0。

## 3. 进度、断点与 CRC

```bash
./weed migrate.volume.status -stateDir=./blob_migrate/state
```

期望相关卷 `status=done`。`Ctrl-C` 后用第 2 步同一条命令再跑，已通过 CRC 的 fid 记为 skipped。

```bash
./weed migrate.volume.verify \
  -mode=blob \
  -masters=127.0.0.1:9334 \
  -dir=./a/data/volume \
  -collection=src_demo \
  -level=crc \
  -onlySuccess \
  -stateDir=./blob_migrate/state
```

期望 `crc_mismatch=0`。

## 4. 核对目标 fid

```bash
ls -l b/data/volume/src_demo_*.dat
./weed export -dir=./b/data/volume -collection=src_demo -volumeId=9
curl -sf "http://127.0.0.1:8081/9,xxxxxxxx" | head
```

把 `9` 和 `9,xxxxxxxx` 换成第 1 步记下的值。`key` 应与源 fid 相同。

## 5. 结束

```bash
./stop.sh a
./stop.sh b
```
