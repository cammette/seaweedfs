# filer 迁移测试

在集群 A 上，把 `src_demo` 卷里的文件经 Filer 写到 `/dst_demo/...`。目标对象落在 `dst_demo_*` 卷，与源卷文件分开。进度写在本目录的 `state/`。

| 角色 | 地址 | 卷目录 |
|------|------|--------|
| 源卷 | 集群 A `a/data/volume` | `src_demo_*.dat` |
| Filer | http://127.0.0.1:8888 | 路径 `/dst_demo/...` |
| 目标卷 | 同一集群 | `dst_demo_*.dat` |

以下命令在 `test-env` 目录执行。

## 1. 准备

```bash
cd /ex-bingo/github/seaweedfs/test-env
(cd .. && go build -o test-env/weed ./weed)
./start.sh a
./prepare_demo_data.sh
```

## 2. 迁移

```bash
./weed migrate.volume \
  -dir=./a/data/volume \
  -collection=src_demo \
  -filer=http://127.0.0.1:8888 \
  -path='/dst_demo/{yyyy}/{yyyyMMdd}/{volume_id}/{hash12}/{fid}' \
  -collectionDst=dst_demo \
  -stateDir=./file_migrate/state \
  -verifyMode=md5 \
  -workers=4 \
  -decompress=true
```

## 3. 进度与校验

```bash
./weed migrate.volume.status -stateDir=./file_migrate/state

./weed migrate.volume.verify \
  -dir=./a/data/volume \
  -collection=src_demo \
  -filer=http://127.0.0.1:8888 \
  -path='/dst_demo/{yyyy}/{yyyyMMdd}/{volume_id}/{hash12}/{fid}' \
  -level=md5 \
  -onlySuccess \
  -stateDir=./file_migrate/state \
  -report=./file_migrate/state/verify_report.json \
  -decompress=true
```

源卷和目标卷应是两批文件：

```bash
ls a/data/volume/src_demo_*.dat
ls a/data/volume/dst_demo_*.dat
```

中断后用第 2 步同一条命令再跑即可续传。重跑整次测试时删除 `file_migrate/state`。
